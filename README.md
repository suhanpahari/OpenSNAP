# OpenSNAP: Open-Vocabulary Segment-and-Query for 3D Point Clouds

**Paper:** [arXiv:XXXX.XXXXX](https://arxiv.org/abs/XXXX.XXXXX)

<p align="center">
  <img src="assets/video/opensnap_explainer.gif" width="85%" alt="OpenSNAP overview">
</p>

OpenSNAP turns a point cloud into a stored relation of objects that can be clicked (mask + name), searched by text, and
queried declaratively, e.g. `SELECT WHERE IS('chair') AND NEAR(IS('table'), 0.5)`, from one room to a whole building.
It builds on the promptable segmenter [SNAP](https://github.com/neu-vi/SNAP). Results and analysis are in the paper;
every number in it is regenerated by the scripts below (tables: [results/TABLES.md](results/TABLES.md)).

## Setup

```bash
git clone --recursive https://github.com/suhanpahari/OpenSNAP opensnap
bash opensnap/install.sh                   # ../env: torch 2.4 + CUDA 12.4, MinkowskiEngine (CUDA 12 patch), viser, Qwen2.5-VL
HF_TOKEN=... bash opensnap/download.sh     # checkpoints, OpenScene data, Replica, Pointcept S3DIS/ScanNet -> ../downloads
bash opensnap/download_compare.sh          # comparative study: Replica (NICE-SLAM), ScanNet frames, OVI-MAP GT, HouseLayout3D, OpenScan
export PYTHONNOUSERSITE=1; cd opensnap
```

Trained checkpoints go in `../downloads/checkpoints/` (`opensnap_text_v4.pth`, `opensnap_click_v3_6k.pth`).
ScanNet needs its terms accepted on Hugging Face (`HF_TOKEN`). All scripts take `--gpus` (GPU ids or MIG UUIDs).

## Reproduce

**Main experiments** (T-tables):

```bash
python scripts/eval_semseg.py --dataset scannet --split val                                   # open-vocab semantic seg.
python scripts/eval_queries.py --dataset s3dis; python scripts/prep_replica.py
python scripts/eval_queries.py --dataset replica --proposals c2f                               # OVQL query workload
python scripts/eval_interactive.py --model snap [--crops 1]                                   # click segmentation
python scripts/eval_naming.py --dataset matterport160 --split test --prior snap+lvis --feature openseg \
       --openscene_ckpt ../downloads/ckpt/matterport_openseg.pth.tar                          # click -> name
python scripts/eval_text.py --dataset scannet --method trained --ckpt ../downloads/checkpoints/opensnap_text_v4.pth
python scripts/eval_proposals.py; python scripts/eval_systems.py; python scripts/eval_building.py
```

Outdoor LiDAR: `prep_nuscenes.py --root <nuScenes>` / `prep_kitti.py --root <SemanticKITTI>`, then the same
`eval_semseg / eval_queries / eval_interactive` scripts with `--dataset nuscenes|semantickitti --domain Outdoor`.

**Comparative study** (C-tables: OVI-MAP, Search3D / OpenMask3D, HouseLayout3D, OpenScan protocols, calibration,
scale, workload, video, qualitative figure), every command with its exact arguments:

```bash
bash scripts/reproduce_compare.sh
```

Settings are chosen on development scenes (S3DIS Area 1 and 30 ScanNet *train* scenes) and applied once to the test
sets. `opensnap/bench.py` reproduces OVI-MAP's official evaluator to five decimals.

**Training** (text decoder): `python scripts/train.py --dataset scannet --arch v4 --num_masks 0 --text_classes 12 --steps 16000`

**Tables:** `python scripts/make_tables.py` → `results/TABLES.md`.

## Use

```bash
python scripts/app.py --scene ../downloads/demo/replica_room0     # viewer at http://localhost:8080 (.npy/.pth/.ply/.pcd/.bin)
```

```python
from opensnap.core import OpenSNAP
from opensnap.snap_model import SnapModel
from opensnap.openscene_model import OpenSceneModel
from opensnap.text import TextEncoder
from opensnap.data import snap_train_vocab
from opensnap.query.catalog import materialize
from opensnap.query.engine import Engine

dense = OpenSceneModel("../downloads/ckpt/matterport_openseg.pth.tar", "openseg")
m = OpenSNAP(SnapModel("../downloads/ckpt/SNAP_C.pth"), TextEncoder("ViT-B/32"), dense, TextEncoder(dense.clip_name),
             anchors=snap_train_vocab())
m.encode(coord)                                                     # (N, 3) XYZ
answers, stats = Engine(m, materialize(m)).run("SELECT WHERE IS('chair') AND NEAR(IS('table'), 0.5) LIMIT 5")
```
